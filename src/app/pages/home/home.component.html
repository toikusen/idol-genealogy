關於 Idol Maps

Idol Maps 是專為台灣地下偶像生態設計的開放資料庫，目前收錄 {{ memberCount }} 位成員、{{ groupCount }} 個團體與 {{ companyCount }} 間公司的資料，並整合台灣北中南演出場地與近期活動行程。

每位成員的頁面記錄了完整的活動履歷，包含跨團體、跨公司的歷史脈絡，讓散落在各社群平台的資訊得以被系統性地保存。資料由社群成員提案貢獻，並經管理員審核後上線。

無論是想查詢某位成員的團體歷史、了解某個團體的成員組成變遷，還是想掌握特定場地的近期演出行程，都可以在這裡找到紀錄。 了解更多關於本站 ，或閱讀 資料閱讀指南 了解本站如何整理公開資料。

什麼是台灣地下偶像？

台灣地下偶像（台灣地偶）是以台灣為主要活動據點的獨立偶像文化，深受日本地下偶像（地下アイドル）影響。不同於主流藝人，地下偶像通常在小型 Live House 或活動會場演出，與粉絲之間的距離更近，握手會、接觸活動是文化核心之一。

台灣地偶圈自 2010 年代中期逐漸成形，目前活躍的團體橫跨台北、台中、高雄等地，類型涵蓋王道、搖滾、樂曲等多元風格。一位成員的完整歷程可能跨越多個團體，資訊散落各處，難以系統性地查詢。

然而，這些資訊往往只存在於粉絲的記憶和已消失的社群貼文裡——Idol Maps 的目標，就是在資訊散佚之前，把每一段活動歷程都記錄下來。

如何使用本站

如何使用 Idol Maps

  1. 在首頁搜尋框輸入成員姓名、暱稱、藝名或團體名稱。
  2. 進入成員頁面查看活動歷程、所屬團體與公司關聯，以及近期演出活動。
  3. 在團體頁面交叉比對成員變動與歷史脈絡，並查看該團體的近期活動行程。
  4. 切換到「場地」分頁，依北中南地區瀏覽各 Live House 與近期活動時程。
  5. 發現缺漏時使用「提案修改」提交補充資料，由編輯審核後更新。

在上方搜尋框輸入成員名字或團體名稱，即可快速找到對應頁面。每位成員的個人頁面列出完整的在籍歷程、與所屬團體的關聯，以及近期演出活動。每個團體頁面呈現成員組成的完整演變，並整合近期活動行程。首頁的「場地」分頁則可依北中南地區查詢 Live House 與活動時程。

發現資料有誤或想補充新的資訊？任何人都可以透過頁面上的「提案修改」送出更新，經管理員審核後上線。詳見 貢獻者手冊。

常見問題

什麼是台灣地下偶像？

台灣地下偶像（台灣地偶）是指以台灣為主要活動地區的獨立偶像藝人，通常在Live House等近距離活動中演出，與主流娛樂圈有所區別。多為多人女子偶像組合，也有個人歌手。

Idol Maps 提供哪些偶像資料？

Idol Maps 收錄台灣地下偶像的成員個人資料、所屬團體歷史、公司關係、活動歷程時間軸、成員間的團體關聯圖，以及北中南演出場地與近期活動行程。資料來源為公開宣傳資料與官方公告，並由社群貢獻者協助維護。

如何查看偶像的近期活動行程？

在首頁切換到「場地」分頁，可以瀏覽台灣北中南各 Live House 與演出場地，並查看近期活動時程。在成員或團體個人頁面也可直接查看該對象的近期演出資訊。

如何在 Idol Maps 搜尋偶像成員？

在 Idol Maps 首頁的搜尋框輸入成員姓名或暱稱，即可快速找到對應的成員頁面。也可以透過成員列表頁依字母或加入日期瀏覽全部成員。

Idol Maps 的資料如何更新？

Idol Maps 的資料由社群貢獻者共同維護，並由編輯審核後上線。若發現資料有誤或缺漏，可透過各個頁面的「提議修改」功能回報，或在聯絡頁面提供補充資料。
